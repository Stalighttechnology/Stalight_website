# Stalight Web — Project Overview

## Description
Stalight Web is the corporate website and customer portal for Stalight Technology, showcasing software development, IT services, skill development programs, product launch previews (Stalight Sync, Stalight Campus), verification portals for certificates/offer letters, and onboarding NDA consent.

## Core Capabilities
- **Product & Service Portals**: Software development, skill acceleration, IT infrastructure, Stalight Sync & Campus.
- **Verification Portal**: Real-time validation for certificates and offer credentials.
- **NDA & Digital Consent**: Browser-based digital signing interface with audit logging.
- **Contact & Inquiries**: Dual-channel inquiry handling via Supabase and EmailJS.

## Tech Stack Summary
- **Frontend**: React 18, TypeScript, Tailwind CSS, Shadcn UI / Radix primitives, Framer Motion.
- **Data & APIs**: Supabase (`@supabase/supabase-js`), TanStack Query, EmailJS.
- **Build & Quality**: Vite, Vitest, ESLint 9.
