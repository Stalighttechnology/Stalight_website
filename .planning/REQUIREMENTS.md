# Project Requirements

## Functional Requirements
- [x] **Responsive Navigation**: Mobile-ready drawer and responsive desktop navigation header.
- [x] **Service & Product Pages**: Dedicated showcase routes for Software Development, IT Services, Skill Development, Stalight Sync, and Stalight Campus.
- [x] **Interactive Contact & Lead Capture**: Supabase-backed contact form submission with instant feedback.
- [x] **Certificate Verification System**: Route to verify certificate IDs and offer letters with dynamic validation status.
- [x] **NDA Onboarding Portal**: Secure digital signing with signature canvas.
- [x] **SEO & Social Cards**: Dynamic page titles and metadata tags via `react-helmet-async`.

## Non-Functional Requirements
- [x] **Performance**: Fast Time to Interactive via route-level code splitting (`React.lazy` + `Suspense`).
- [x] **Type Safety**: 100% strict TypeScript typing.
- [ ] **Test Coverage**: Establish Vitest unit tests for critical utility functions and API services.
